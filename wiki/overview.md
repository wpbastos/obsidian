# Vault Overview

This Obsidian vault is a shared second brain for Claude Code across all projects.

Knowledge is explicitly captured (no auto-memory), curated into a wiki, and readable by Claude from any project directory. It covers three domains: personal knowledge and notes (D), GitHub and codebase-specific context (B), and research and external sources (E).

Sources dropped into `.raw/` are ingested and promoted into structured wiki pages. The `wiki/hot.md` file carries the most recent context and is always loaded first. Use `/save` to file useful takeaways at the end of any session, and `/wiki-lint` periodically to keep the vault clean and the hot cache current.
